## 1. 这个项目是什么

ESP32-S3 + ES7210 + 4 麦克风阵列(40mm 十字),两套功能 **二选一**(编译时切换):

| 模式 | 功能 | 输出 |
| --- | --- | --- |
| **声源定位**(默认) | GCC-PHAT + SRP-PHAT 实时估计声音方位 | 16 灯方向环 + 网页罗盘 |
| **音色识别** | Edge Impulse INT8 模型(鸟叫/噪声 3 类) | 灯环检测指示 + 网页置信度 |

模式开关在 **`main/app_mode.h`**(一行 define,改完重新编译烧录):

```c
#define APP_MODE  APP_MODE_SOUND_LOCALIZATION   // ← 当前: 声源定位
// #define APP_MODE  APP_MODE_SOUND_CLASSIFY    // ← 改成这个: 音色识别
```

注意事项:
- **串口号会变**(板子重新插拔/换板会换 COM 号)。用设备管理器或
  `python -c "import serial.tools.list_ports; [print(p) for p in serial.tools.list_ports.comports()]"`
  找 **USB VID:PID=303A:1001** 的那个(303A=乐鑫)。
- 烧录后看串口应出现 `bird_det` 日志。如果只有 `board_test` 日志,说明
  `main/board_test/board_test.h` 里的 `ENABLE_BOARD_TEST` 开关还开着,注释掉重烧。
- IDF 5.4.2 装在 `C:\esp\v5.4.2`;**不要用 EIM 装的 v6.1**(es7210 组件不兼容)。

## 4. 调试:串口日志字段详解

定位模式每 8 帧打一行(~171ms),字段含义:

```
DOA=217.4°  跟踪器输出的最终方向 (网页/灯环显示的就是它经门控后的值)
raw=215.2°  本帧 SRP 原始估计 (未标定平滑, 抖动大, 只用于参考)
rms=[..]    四路宽带 RMS (归一化, 1.0=满量程)
tr=0.0396   8ms 峰值块 RMS (瞬态强度); pr=1.41  峰值块/全帧比 (响指>2)
srp=0.038   SRP 主峰分数; second=0.022 次峰分数
conf=0.35   置信度 = (主峰-次峰)/主峰, 越高方向越可信
mir=0.12    ★ 镜像比: 对侧(+180°)分数/主峰。>0.6 说明本帧方向含糊(对侧伪影)
br=0.0009   ★ 带内(1.5~6kHz) RMS, 激活/跟踪门控的能量来源
fl=0.0002   ★ 跟踪的带内噪声底 (门限 = max(绝对下限, fl×倍率))
act=1       ★ 声源激活 (能量过门限)
dsp=1       ★ 显示激活 (LED/网页真的在显示)
oc=0        削顶样本数 (>20 说明这帧打满了, SRP 不可信, 走近场 onset 通道)
status=valid/rejected   本帧是否被跟踪器接受
```

判断问题的顺序:先看 `act` 有没有亮 → 没有 = 能量/门限问题(调第 6 节的灵敏度);
act 亮了 `dsp` 不亮 = 跟踪/门控问题;都亮但方向错 = 看 `mir`(镜像)和 `oc`(削顶)。

## 6. 调参速查表 (症状 → 旋钮)

所有参数集中在两个文件:`main/main.c` 顶部 和 `main/doa/*.c` 顶部。

| 症状 | 调什么 | 文件 |
| --- | --- | --- |
| 小声/远的声音不亮灯 | `LED_SNR_WEAK_RATIO` 1.8 → 1.6 (更灵敏, 可能误亮) | bird_doa_demo.c |
| 环境噪声让灯常亮 | `LED_SNR_WEAK_RATIO` ↑ 或 `LED_WEAK_SRP_CONF_THRESHOLD` ↑ | 同上 |
| 灯跟着音乐方向乱跳 | `SRP_EMA_SUSTAINED` 0.15 → 0.10 (积分更长, 响应更慢) | bird_doa_demo.c |
| 方向跳变太敏感/太迟钝 | `OPPOSITE_STABLE_FRAMES`(对侧跳变确认帧数)、`HIGH_CONFIDENCE_JUMP` | doa_tracker.c |
| 响指亮对面 | `TRANSIENT_MIRROR_RATIO_MAX` 0.60 ↓ (更严格拒绝对侧含糊帧) | bird_doa_demo.c |
| 灯切换太生硬 | `LED_SWEEP_STEP_DEG` 25 → 15 (滑得更慢更优雅) | led/led_indicator.c |
| 熄灭太慢/太快 | `LED_OFF_HOLD_FRAMES` 45 (帧, ~1s) | bird_doa_demo.c |
| 整体太灵/太钝 | `ES7210_VOL` 数字增益 ±6dB 一档 (改后看 fl 是否贴近环境) | bird_doa_demo.c |
| 角度整体偏一个固定值 | `BOARD_DOA_MIRROR_AXIS_DEG` 加偏移常量 | direction_mapping.c |

**改采样率必须重算 GCC_HP_ALPHA/GCC_LP_ALPHA**(系数与 Fs 绑定,公式见注释)——
这是历史上"距离减半"事故的根因。

## 8. 已知边界 (不是 bug, 是物理)

1. **音量-距离**:声源响度直接决定检测距离。正常听音音量下音乐 2~3m 可稳;把音量
   关到勉强可闻,2m 处带内 SNR 只剩 2~4dB,任何算法都检不出。
2. **近场 <50cm**:远场平面波假设失效,敲击响指方向偏差可达 ~30°;强瞬态会把 ADC
   打削顶(日志 oc>0),此时走近场 onset 通道(粗定位,±1~2 灯)。
3. **镜像(亮对面)**:十字阵列中心对称 + 对径基线 80mm 在 >2.14kHz 空间混叠,
   是固有几何问题。已有三道防线(镜像门控/5 帧确认/onset 通道),彻底解决要改板:
   加大孔径 + 打破 180° 对称(把某颗麦偏移 5~8mm)。
4. **角度精度**:40mm 孔径的物理上限约 ±5~10°,网页罗盘±19° 内的游走属正常。
