# 声源定位参数与动态灯效说明

适用工程：`i2s_es7210_sound (4)/i2s_es7210_sound`，ESP32-S3、ES7210、四麦十字阵列、16颗WS2812。阵列**半径40毫米、对径80毫米**，GPIO1输出灯带信号。

当前默认采用文末“连续绕圈跟随”版本。先前稳定停留策略只保留为调试历史。

本次以已验收的主方向定位为基础：补齐参数注释，增加独立灯效渲染与保守双峰显示，不重新调节主方向灵敏度、镜像保护及坐标映射。以前的调试结果见《声源定位调试_2026-11-18.md》。

## 开箱表现

- **固定声源**：对应灯位柔和呼吸，周期1.8秒；最低保持峰值亮度的70%，不通过全灭闪烁影响观察方向。
- **连续移动显示**：主灯跟随已认可的连续角度，以32ms环形平滑依次经过灯环。顺、逆时针都能跨过0°；移动时主灯稳亮，后方仅一颗相邻暗尾灯（上限10%），停止后160ms淡出。不再逐灯等待280/450ms。
- **两个可分辨方向**：两个方向各自亮起、各自按收到的方向声强调整亮度；双方向时不叠加两条拖尾，以免变成三四颗灯。对本四麦阵列保守限制为最多2个方向，间隔至少60°，并额外持续确认。
- **RGB颜色**：弱声为蓝/青，增强后向绿/暖黄变化；也可改成固定蓝色、绿色或任意RGB。
- **停止/变弱**：保留原有定位显示保持，再平滑淡出；音频任务停止供数超过200毫秒时，渲染器也会自行淡出，防止死灯粘亮。

亮度对应的是**麦克风接收到的声音强度**，不是距离测量。音量大的远处音源可以比小声的近处音源更亮；音源自身音量、房间反射、遮挡和麦克风频响均会影响亮度。

### 强度计算

先计算 `power = max(signal_rms² - noise_rms², 0)`，再用 `10*log10(power)` 转成dBFS，最后在 -60～-25dBFS之间映射为0～1。它与空间置信度分开：**置信度决定是否接受方向，RMS决定已接受方向有多亮**。不会用“置信越高”伪装成“距离越近”。

单方向使用实际滤波带内RMS；两个方向分别做四通道的延时求和波束，得到各方向的接收RMS。不同方向的强度估计仍有互相泄漏、反射和频谱差异，不是高精度声压计或独立源分离器。

仅 `APP_MODE_SOUND_CLASSIFY` 使用：16kHz、抽取比3、12抽头抗混叠FIR；静音RMS门槛.0015，分类置信EMA .55。分类AGC目标RMS .045，允许线性增益.70～6.0，低于.0012不大幅放大，增益EMA .09；切输入通道需强度高出35%。当前为单缓冲队列移交，推理期间不覆写。**这些AGC参数不控制定位灯光强度。**

## 双方向显示的依据与门槛

`gcc_phat.c`从原空间图提取局部峰，主方向原有的`angle_deg/score/confidence/valid`不变。不会把最大的两个数组元素、同一宽峰的肩部或 `second_score`直接当成两个音源。

| 参数 | 默认 | 含义 |
|---|---:|---|
| `DISPLAY_PEAK_MIN_SEPARATION_DEG` | 60° | 两峰最小间隔 |
| `DISPLAY_PEAK_MIN_SCORE` | .012 | 每个峰的最低空间分数 |
| `DISPLAY_PEAK_MIN_RATIO` | .55 | 次峰至少达到主峰55% |
| `DISPLAY_PEAK_MIN_PROMINENCE` | .12 | 峰相对±20°两侧谷底的突出度 |
| `DISPLAY_PEAK_MIN_PAIR_SUPPORT` | 4 | 六个麦对中至少四对在相应延时有正支持 |
| `DISPLAY_PEAK_MAX_MIRROR` | .75 | 对侧分数高时额外审查 |
| `DISPLAY_PEAK_OPPOSITE_PROMINENCE` | .25 | 对向双峰只有同时形成明显尖峰才保留 |
| `MULTI_CONFIRM_MS` | 500ms | 两峰至少共同稳定这么久 |
| `MULTI_CONFIRM_FRAMES` | 12 | 同时要求至少十二次连续观测，未确认前缺峰即重置 |
| `MULTI_MATCH_DEG` | 18° | 观测之间的方向匹配容差 |
| `MULTI_BRIDGE_MS` | 120ms | 缺失一个峰的短时间保持，之后退回主方向 |

两个音源强弱交换时按角度距离关联，不因峰排序换位而把灯画成绕圈。主方向进入灯效的是已认可的连续主跟踪角副本，不再把它量化成22.5°的灯位中心；只有跟踪与显示有效时才更新副本。串口DOA与网页display_angle均保持原本的数据路径，副本只用于灯光。

**限制**：反射也可能形成稳定第二峰，四麦SRP不能保证把真实双源与一源加回声全部分开。相距小于60°、两源强弱悬殊、纯音、多于两源时，可能只显示主方向。单方向换位只允许“主灯+一颗相连尾灯”，不会因插值同时出现多个零散亮点；双方向的两个主灯必须另经过持续确认。双向显示是实际空间候选，不能写成“任意多声源准确识别”或“按距离精确变亮”。

## 响应与渲染

`led_submit_scene()`只在极短临界区复制最新场景，不等待灯带发送，不排队播放过时方向。渲染器按真实毫秒计时，以50Hz独立运行；先合成整帧RGB，再一次刷新。连续角度的三个同向小步进入跟随模式，直接更新显示目标，并以32ms环形平滑跟随；不再在每个相邻灯位强制停450ms。孤立的阶跃仍会确认120ms，大角突变确认180ms，避免零散瞬闪。强度上升35ms、下降180ms。

主灯为显示角附近的最亮像素，边界保留1.5°轻微回差；单方向最多只有“亮主灯+一颗暗尾灯”。尾灯由运动方向决定，固定在主灯后方一个物理相邻灯位，上限10%，不叠加历史散点；移动停止后160ms二次曲线衰减。移动时取消呼吸调制，主灯稳亮，静止后恢复柔和呼吸。原始声学跟踪与确认仍有自身延迟；显示不能凭空补出定位器没输出的方向，也不自动绕圈。

`led_all_off()`在动态模式下由唯一渲染任务于下一周期清屏，避免并发操作RMT。分类全环点亮仍使用原独立模式，不同时启动定位动画。

## 验证及回退

- 主机灯效测试覆盖：常驻单灯呼吸不全灭、强度单调性、RGB变化、跨0°相邻短拖尾、大角变化只切主灯而无远处残影、双源强弱独立、峰排序交换、无效数值、失活淡出、双峰持续确认/消失。额外用连续10秒、每100毫秒在两个相邻目标间来回变化的输入，检查显示灯不追着跳；连续10秒注入单帧远方离群，确认不会闪出远灯；缺峰时未确认的双峰候选会立即清零，不能把断续假峰累计成第二灯。
- 算法测试加入独立双源解析波形（0°/90°、20°/130°、300°/60°、0°/180°）；这只是已知方向算法验证，不替代实机双扬声器声学测试。
- 保存的单源真实四通道录音重放：环境936帧、语音1123帧、弱声1452帧，均未被持续确认成双方向场景；不能因此保证所有房间零回声误亮。
- 原有方向、弱声和LED原子刷新的回归仍保留。真实录音实机负载与停止观察见本文件后续结果。
