# 使用指南 · 声源定位 + 音色识别开发板

> 面向**刚拿到板子**的用户:从开箱到玩起来,只讲操作,不讲原理。
> 开发/调试向的内容见 `docs/新人指南.md`,项目卖点和结构见 `README.md`。

---

## 1. 开箱认识

板子上有这些东西,先混个眼熟:

| 部件 | 位置/外观 | 干什么用 |
| ---- | ---- | ---- |
| 4 × 麦克风 | 板面中央十字排列的小金属贴片 | 拾音,用于定位和识别 |
| 16 × RGB 灯环 | 板面一圈彩色 LED | 指向声源方向 / 识别命中指示 |
| USB-C 口 | 板边 | 供电 + 烧录 + 串口日志,一根线全包 |
| 蜂鸣器 | 板面黑色小圆(背面 NPN 驱动) | 自检时发声 |
| 排针 | 板边多组 | I2C / UART / IO / ADC 扩展(玩例程用) |

**供电**:USB-C 接充电宝/手机充电器即可,不接电脑也能跑。

---

## 2. 第一次上电(1 分钟)

1. USB-C 线接上电源
2. 等约 5 秒(固件启动 + 连 Wi-Fi)
3. **对它拍个手** —— 灯环会亮成一条指向你拍手方向的光带,这就是声源定位在工作

上电后灯环默认熄灭 = 待机,有声音才会亮。默认固件是**声源定位模式**。

> 注意:此时它连的是**出厂写死的 Wi-Fi**(见下节),如果那个 Wi-Fi 不在身边,
> 板子会以离线模式继续跑定位(灯环正常),只是没有手机面板。

---

## 3. 连上你家 Wi-Fi,打开手机面板(唯一要改代码的地方)

Wi-Fi 账号密码是编译时写死的,打开 `main/wifi/wifi_server.h`,改最上面两行:

```c
#define WIFI_SSID       "你家Wi-Fi名字"
#define WIFI_PASSWORD   "你家Wi-Fi密码"
```

然后重新编译烧录(需要装 ESP-IDF,见第 6 节;VS Code ESP-IDF 插件用户直接点烧录按钮即可)。

烧录完成后:

1. 用 USB 线连电脑,打开串口监视器(115200),找到这一行:

   ```
   I (xxx) wifi_server: 已连接, IP: 192.168.1.23
   ```

2. **手机连到同一个 Wi-Fi**,浏览器打开这个 IP(如 `http://192.168.1.23`)
3. 出现罗盘页面:拍手,罗盘指针和灯环同步指向声源

面板是局域网内的,不出外网,不需要注册任何账号。

## 4. 日常玩法

| 玩法 | 操作 | 现象 |
| ---- | ---- | ---- |
| 定位 | 在板子不同方向拍手/说话 | 灯环沿最短路径滑向声源方位,网页罗盘同步 |
| 距离测试 | 逐渐退远发声 | 几米内正常;太远或音量太小灯环不亮(灵敏度边界) |
| 音色识别 | 见第 5 节切模式后,播放鸟叫 | 灯环全亮,网页显示 bird/noise 置信度 |
| 响指 | 打个响指 | 快速路径直接跳转指向,无需等待 |

**已知边界**(不是坏,是物理规律):
- 声源距离板子 **<50cm** 时方向可能偏差较大(近场,阵列假设失效)
- 对着板子正对面 180° 方向的突发声,偶发指向对面(对称阵列的固有模糊)
- 纯噪声(如白噪声音箱)没有明确方向,定位无意义

## 5. 切换功能:定位 / 识别 / 例程 / 自检

所有切换都是**改一行注释 → 重新编译烧录**:

| 想跑什么 | 改哪个文件 | 改哪行 |
| ---- | ---- | ---- |
| 声源定位(默认) | `main/app_mode.h` | `#define APP_MODE  APP_MODE_SOUND_LOCALIZATION` |
| 音色识别 | `main/app_mode.h` | `#define APP_MODE  APP_MODE_SOUND_CLASSIFY` |
| 单个外设例程(I2C/ADC/UART/RGB/录音/USB/BLE) | `main/examples/examples.h` | 去掉对应 `//RUN_EXAMPLE_xxx` 的注释 |
| 板级全外设自检(生产用) | `main/examples/examples.h` | 去掉 `//RUN_EXAMPLE_BOARD_TEST` 的注释 |

> 定位模式不跑神经网络,内存和 CPU 占用更低;识别模式显示置信度、隐藏罗盘。
> 两种模式都改完 `app_mode.h` 后重新烧录生效,`examples.h` 的例程同理。

**板级自检**额外需要一台 PC 接收录音:电脑上运行 `python tools/upload_server.py`,
浏览器打开 `http://<电脑IP>:8080/` 可在线回放每个麦克风的录音(排查坏麦)。

## 6. 怎么编译烧录(第一次玩固件必读)

1. 装 [ESP-IDF v5.4](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/get-started/)
   (本机已装好 v5.4.2 的,直接用 `C:\esp\v5.4.2\build_project.bat`)
2. USB-C 连电脑,确认串口号(Windows 设备管理器,如 COM26)
3. 编译 + 烧录 + 看日志一条龙:

   ```bash
   idf.py -p COM26 flash monitor
   ```

4. 退出串口监视器按 `Ctrl+]`

## 7. 常见问题

**Q:Wi-Fi 连不上会炸吗?**
不会。重试 3 次后转入离线模式,定位照常跑,串口会提示
`Wi-Fi 连接失败, 系统将以离线模式运行`。改对 SSID/密码重新烧录即可。

**Q:手机打开 IP 是白屏/打不开?**
确认手机和板子连的是**同一个 Wi-Fi**(很多路由器 2.4G/5G 是两个名字,
本板只支持 2.4G);确认 IP 是串口日志里打印的那个。

**Q:灯环完全不亮?**
先确认编译进去的是默认固件(例程开关全部注释);拍手音量要大一点;
还不行跑一遍板级自检(第 5 节)看 LED 项是否 PASS。

**Q:方向感觉不准?**
- 声源离板子近于 50cm → 退远点
- 板子摆放方向和网页罗盘有固定偏差 → 改 `main/doa/direction_mapping.c` 的标定角
- 详细调参见 `docs/新人指南.md` 的调参速查表

**Q:识别模式放了鸟叫没反应?**
音量-距离是硬约束:音箱音量太小、距离太远,信号到麦上就没了。
先近距离大音量验证链路,再逐步拉远找边界。

**Q:想识别别的东西(狗叫/人声)或换 LED 效果?**
见 `README.md` 的"二次开发建议"一节,换模型 = 替换 `bird-sound-cpp-mcu-v2/tflite-model/`。
