#  声源定位 · 鸟声识别开发板

## 让每一只鸟的歌唱, 都有方向

**ESP32-S3 · 四麦克风阵列 · 端侧 AI · 免云端**

---

### 它能做什么？

想象一下: 花园里有鸟叫, 这块板子不仅能**听出那是鸟叫**, 还能**告诉你鸟在哪个方向**——

 **听得到** —— 4 颗高灵敏度 MEMS 麦克风组成 40mm 十字阵列, 48kHz 专业级采样率, 远处的鸟鸣、树梢的浅唱都逃不过它的"耳朵"

 **找得到** —— GCC-PHAT + SRP-PHAT 双算法加持, 2° 精细搜索栅格, 0~360° 全向定位; 一旦锁定, 16 颗 RGB 灯环**实时点亮声源方向**, 眼睛不用盯着屏幕, 一眼看清"它在哪"

 **分得清** —— Edge Impulse 端侧 AI 模型 (INT8 量化), 鸟声还是噪声? 板子自己判断, **不联网、不掏云费用、不泄露隐私**, 数据一个字节都不出设备

 **看得见** —— 手机连上同一 Wi-Fi, 浏览器输入设备 IP, 实时声学罗盘 + 置信度曲线立刻呈现, 零安装零配置

 **连得上** —— 板载蓝牙 BLE 5.0, 手机 App 直连无门槛: 连接 "ES7210-DOA" 即可读写数据, 无线串口、数据透传、智能家居联动, 想怎么玩都行

 **还很好玩** —— 对着板子拍个手, 灯环瞬间指向你! 拍手瞬态快速路径让响应快至毫秒级, 派对上绝对是吸睛神器

---

### 为什么选它?

 **不是玩具, 是真算法**: 微秒级时差测量 + 全向功率搜索, 同价位板子给不了的真实声学定位能力

 **端侧 AI, 隐私安全**: 识别推理全部在芯片上完成, 断网照样工作

 **例程齐全, 拿来就能学**: I2C、ADC、UART、RGB、I2S 录音、USB 串口、蓝牙 BLE——七个官方例程风格的外设示例, 每个独立成文件、标注所用引脚与接线方式, ESP32 初学者也能看懂每一行

 **自带生产自检**: 出厂前一键全外设检测, 麦克风录音自动上传电脑在线回放——品控看得见, 买得放心

 **开源可魔改**: 想识别狗叫? 猫叫? 口哨? 玻璃破碎声? 用 Edge Impulse 训练自己的模型换上去就行; 定位精度、灯效、面板样式全部代码可调

---

### 典型应用

-  **观鸟神器**: 后院挂一个, 鸟一来灯就亮, 方向一目了然
-  **嵌入式/AI 教学**: 声学阵列 + 端侧推理 + FreeRTOS 多任务, 一块板讲透一门课
-  **声学项目原型**: 机器人听觉、智能音箱原型、声控互动装置
-  **智能监测**: 异响检测、声源追踪监控的快速原型

### 技术规格

| 项目 | 参数 |
| ---- | ---- |
| 主控 | ESP32-S3 双核 240MHz |
| 麦克风 | 4 × SPH1642HT5H (十字阵列, 40mm 孔径) |
| 音频 ADC | ES7210, 4ch TDM 同步采集 |
| 采样率 | 48kHz / 16bit |
| 定位算法 | GCC-PHAT + SRP-PHAT, 2° 栅格 |
| 识别模型 | TFLite Micro INT8 端侧推理 |
| 指示 | 16 × WS2812 RGB 灯环 |
| 无线 | Wi-Fi 802.11 b/g/n (2.4GHz) + 蓝牙 BLE 5.0 |
| 接口 | USB-C ×1, I2C ×2, UART ×2, ADC ×2, IO ×8 |
| 供电 | USB-C 5V |
