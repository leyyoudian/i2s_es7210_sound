# WS2812 DOA Mapping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drive the revised ten-pixel WS2812 ring and correct GCC-PHAT channel orientation for the unchanged four-microphone geometry.

**Architecture:** Keep the audio task and public LED API intact. Isolate circular-angle selection in a hardware-independent C module, while `led_indicator.c` owns the ESP-IDF `led_strip` handle and RMT output.

**Tech Stack:** ESP-IDF 5.4.2, C, Espressif `led_strip`, RMT, host GCC tests, pytest.

## Global Constraints

- WS2812 data GPIO is GPIO3.
- Pixel electrical order is U24 through U33.
- Pixel angles are 22.5, 337.5, 315, 292.5, 247.5, 202.5, 157.5, 135, 112.5, and 67.5 degrees.
- Physical microphone angles are MIC3=0, MIC4=90, MIC2=180, MIC1=270 degrees.
- Preserve the existing public LED API.
